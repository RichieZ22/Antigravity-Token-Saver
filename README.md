# Antigravity-Token-Saver

(English)

To my fellow independent game developers and software engineers who use Antigravity: this tool is perfect for you. Simply place an `AGENTS.md` file into your project directory, and you can pick up right where you left off within Antigravity. This file contains no malicious code; its contents consist solely of rules that Antigravity is designed to interpret. Happy coding, everyone!

(Türkçe)

Antigravity ile kod yazan bağımsız oyun yapımcıları, veya uygulamalar geliştiren yazılımcı arkadaşlarım. Bu araç tam size göre. Tek yapmanız gereken şey proje dosyanıza AGENTS.md dosyasını bırakmak ve antigravity'de işlemlerinize kaldığınız yerden devam etmek. Bu dosya zararlı yazılım içermemekte olup içeriği sadece antigravity'nin anlayacağı kurallar ile mevcuttur. Herkese iyi çalışmalar dilerim!
